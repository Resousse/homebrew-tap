# Resousse Tap

## How do I install these formulae?

`brew install resousse/tap/<formula>`

Or `brew tap resousse/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "resousse/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
